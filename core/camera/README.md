# :core:camera

Camera2 工作階段與擷取請求。

| 項目 | 內容 |
| --- | --- |
| 職責 | 開啟實體鏡頭、組裝預覽與拍攝請求、白平衡套用（ADR-0002）、曝光換算（ADR-0009）、閃光燈硬關（FR-81） |
| 依賴 | `:core:profile`；**不得**依賴 `:core:telemetry`（ADR-0007），深度段以數值從 `:app` 傳入 |
| 對應需求 | FR-11、FR-15、FR-21、FR-31、FR-35、FR-81、FR-91 |
| 內容 | `preset/PresetTable`：五種預設的最長曝光與 AF 策略（FR-11，mvp-scope.md 第 4 節初稿）<br>`exposure/ShutterPriority`：預覽測光換算為快門優先（ADR-0009）<br>`request/RequestPlanner`：組出預覽與拍攝的 `RequestSpec`（鏡頭、AE、AF、白平衡），純資料<br>`request/CaptureRequestWriter`：把 `RequestSpec` 寫成 Camera2 鍵；實體鏡頭可設的鍵同時用 `setPhysicalCameraKey`；每個請求 `FLASH_MODE_OFF`；矩陣用分母 65536（`FixedPoint`），HAL 的 1/256 格點可精確表示<br>`session/CameraController`：對 UI 的唯一入口（ADR-0001），`start`／`select`／`capture`／`stop`，狀態以 `StateFlow<CameraState>` 提供，每幀預覽結果以 `previewFrames` 提供，每次 AUTO 對焦的結果以 `focusScans` 提供；Camera2 工作都在專用 HandlerThread<br>`focus/AfScan`：判斷一次 AUTO 對焦的結果（鎖定、失敗、逾時；觸發前的結果不採用；搜尋 0.4 s 以計時器準時判定逾時，使改用固定距離落在 FR-35 的 0.5 s 內），純邏輯<br>`focus/BracketPlanner`：FR-33 焦點包圍規劃（ADR-0014）：依超焦距與放大倍率算景深，以 0.7 倍步進從主體近端排到遠端；APPROXIMATE 多一張、UNCALIBRATED 無校正表時不規劃、校正偏移換算、太近與超出張數上限時標示；尚未接上<br>`session/FocusScanner`：微距等 AUTO 對焦預設進入時觸發一次對焦，失敗或逾時改用該預設的固定距離直到離開；拍照與連拍前等待對焦完成（FR-31、FR-35，[m4-af-timeline.md](../../docs/test/m4-af-timeline.md)）<br>`session/ReportedSettings`：拍攝結果回報的曝光、AF、AWB 與色彩值，供比對請求<br>`session/BurstStream`：連拍工作階段（預覽 + 一般 JPEG），`CameraController.burst()` 換入、放開後換回（FR-15、FR-68）<br>`session/RawReaders`、`RawFrame`：每個鏡頭一個 RAW reader，跨工作階段保留，RAW 全部釋放後才關；`hasRoom()` 在已交出 7 張時讓拍照不加 RAW，避免相機執行緒崩潰；`RawFrame` 持有 RAW `Image` 與實體鏡頭的特性與結果，由擁有者關閉（ADR-0005）<br>`session/LensSwitcher`、`LensStream`：logical camera 0，每個實體鏡頭一個 session（預覽 + JPEG\_R + RAW；JPEG\_R 與 JPEG 不可同一 session），換鏡頭才重建 session，重建前先 `abortCaptures()`；連拍放開後在 logcat（標籤 `LensSwitcher`）記錄 `burst resume` 各步驟耗時（[m2-burst-resume.md](../../docs/test/m2-burst-resume.md)）<br>`session/PreviewMeter`：預覽自動曝光當測光表（ADR-0009），保存最新的曝光時間與 ISO、回報每幀預覽（NFR-4 計時）、把結果交給 `FocusScanner` |
| 測試 | JVM 單元測試：預設參數、曝光換算、請求組裝、AF 對焦判斷（`AfScanTest`）、焦點包圍規劃（`BracketPlannerTest`）、FR-81 閃光燈防護（`AeMode` 只有 ON/OFF；掃描 `:core:camera` 與 `:app` 原始碼不得出現閃光燈或手電筒模式）<br>實機儀器測試（`src/androidTest/.../acceptance/`）：`PresetSwitchTest`（FR-11、NFR-4 切換）、`StillCaptureTest`（NFR-4 快門、FR-61a）、`DarkRoomFlashTest`（FR-81，需遮住鏡頭單獨執行）、`MacroFocusTest`（FR-35、FR-31，鏡頭前 5 cm 放印刷頁）；共用 `CameraRig.capture()` 拍完立即歸還 RAW；結果見 [m1-instrumented.md](../../docs/test/m1-instrumented.md)、[m4-af-timeline.md](../../docs/test/m4-af-timeline.md)<br>實驗（`src/androidTest/.../experiment/`）：`StreamComboExperiment`（M2 工作階段組合，[m2-stream-combos.md](../../docs/test/m2-stream-combos.md)）、`AfTimelineExperiment`（各鏡頭 AF 狀態時間軸，以 `-e scene` 標記場景，[m4-af-timeline.md](../../docs/test/m4-af-timeline.md)）、`MacroFocusExperiment` 與 `RawRig`（微距待測清單 T0、T1、T3、T9：以 AF 估目標距離、望遠實體串流手動對焦、已知距離附近細掃、焦點包圍時間，[m9-macro-land.md](../../docs/test/m9-macro-land.md)）、`VideoStreamExperiment` 與 `EncoderSink`（ADR-0011 驗證 4、5：預覽＋硬體編碼器＋照片的 30 / 60 fps 組合、錄影中拍照，[m7-logical-zoom.md](../../docs/test/m7-logical-zoom.md) 第 4 節）、`LogicalZoomExperiment`（ADR-0011 第一階段：驗證一節第 4 項的串流組合能否建立，及第 1、3 項的連續變焦換鏡頭與各倍率拍照尺寸；第 2、5 項未涵蓋，跑完不足以採納；尚未執行） |
