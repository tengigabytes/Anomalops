# 4. 使用情境與使用者角色

[← 需求文件索引](README.md)

v1 只服務一種人：持有 AOW 以上證照、用 SeaTouch 防水殼搭配一支持續光潛水燈的休閒潛水員，在 5–35 m、能見度 5–30 m 的熱帶至溫帶海域拍攝。自由潛水與浮潛是次要情境，需求相容但不為其優化。

| 情境 | 深度 / 光線 | 主體 | 難點 |
| --- | --- | --- | --- |
| 下水前 | 岸上 / 船上、日光 | 岸潛環境、船上風景、裝備、潛伴 | 手機已在殼內，需陸上白平衡與一般相機行為；鏡頭罩水珠 |
| 水面 | 0 m、日光或夜間船燈 | 潛伴下水、等船的人、浪、船、半水半空 | 高對比（天空 vs 水下）、鏡頭罩水珠、夜潛低光、水面搖晃 |
| 廣角造景 | 5–20 m、自然光 | 珊瑚群、沈船、潛伴 | 藍綠色偏、對比低、懸浮物 |
| 中景魚群 | 10–30 m、自然光 + 潛水燈 | 魚群、海龜、大型生物 | 主體移動快、快門時機、AF 追焦 |
| 微距 | 任何深度、潛水燈為主 | 海蛞蝓、蝦蟹、海馬、小型小丑魚 | 對焦距離短、浮力控制中單手操作 |
| 洞穴 / 沈船內 | 低光 | 結構、光束 | 高 ISO 噪點、高對比 |
| 安全停留 | 5 m、強光 | 潛伴、水面光束 | 前後搖晃、水面逆光過曝 |
| 出水後 | 船上 / 岸上 | 無 | 快速回看、刪除失敗連拍、標註物種、對齊潛水電腦資料 |

典型一趟的使用流程（對應後續 FR 編號）：

1. 上船前：選潛點預設、確認濾鏡設定、進入潛水鎖定模式（FR-1x、FR-7x）。
2. 下水後：單手切換場景、一鍵白平衡、拍照 / 錄影（FR-2x、FR-3x、FR-4x）。
3. 出水後：解鎖、同步潛水電腦、批次色彩還原、標註物種、分享（FR-5x、FR-6x）。

Anomalops 的每一項需求都應回答「這能不能在水下單手一步完成」。
