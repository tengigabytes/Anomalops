# 5.5 潛水鎖定與操作

[← 需求文件索引](README.md)

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-51 | 潛水鎖定模式：全螢幕、鎖定方向、最高亮度、屏蔽通知與手勢導覽、螢幕永不休眠 | 在殼內不會因誤觸退出 APP；解鎖需長按 3 s | P0 必要 |
| FR-52 | 快門為螢幕短邊整條區域（寬度扣除 FR-55 兩側安全區）；按下即拍第一張，按住超過 400 ms 轉為連拍；不使用拖曳與多點手勢 | 目標寬度 ≥ 88 dp，在 SeaTouch 凝膠膜下誤觸率 < 5% | P0 必要 |
| FR-53 | 音量鍵作為備用快門（若防水殼可按到） | 可在設定中開關 | P1 應有 |
| FR-54 | 色彩直方圖與過曝警示（斑馬紋）可在預設中開關 | 不遮住主體中央 60% 區域 | P2 可選 |
| FR-55 | 邊緣安全區：潛水鎖定畫面的所有可點擊元件距螢幕四邊 ≥ 12 mm（約 76 dp；執行時以 DisplayMetrics.xdpi / ydpi 換算實體 mm），避免在凝膠膜與殼框交接處按壓 | 邊緣帶只放唯讀資訊，不放任何控制元件；以殼內實機量測可按區域後定稿 | P0 必要 |
| FR-56 | 不依賴系統鎖定螢幕：Activity 設為 showWhenLocked + turnScreenOn，即使電源鍵被誤按或系統鎖定，相機畫面仍可直接回到（安全相機模式，相簿只限本趟） | 鎖定狀態下單點螢幕即回到預覽，不需指紋、臉部或滑動 | P0 必要 |
| FR-57 | APP 內待機：60 s 無操作後將預覽降為 10 fps、亮度降至 30%，點擊任一處即恢復；不交給 OS 休眠 | 恢復至可拍攝 ≤ 300 ms；待機下耗電降至預覽的 50% 以下 | P1 應有 |
| FR-58 | 下水前檢查清單：進入潛水鎖定前提示電量、剩餘容量、閃光燈已關、濾鏡設定、潛水電腦時鐘已對時 | 一頁、一鍵確認 | P1 應有 |
