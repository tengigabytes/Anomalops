# 5.4 潛水資訊與中繼資料

[← 需求文件索引](README.md)

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-41 | 畫面疊加顯示潛水時間、目前白平衡段、電量、剩餘容量、羅盤方位 | 字高 ≥ 16 sp，強光下可讀 | P1 應有 |
| FR-42 | 下水前最後 GPS 定位寫入整趟照片 EXIF | 每張照片含潛點座標 | P1 應有 |
| FR-43 | 手動深度標記：點選深度段即寫入後續照片的自訂 EXIF 欄位 | 不超過兩次點擊 | P2 可選 |
| FR-44 | 出水後匯入潛水電腦 Log（UDDF / Subsurface 匯出），以時間戳對齊每張照片的深度與水溫，寫入 EXIF（對應 TG-7 Field Sensor） | 對齊誤差 ≤ 5 s，可手動修正時鐘偏移 | P1 應有 |
| FR-45 | 感測器背景記錄：潛水鎖定期間以 1 Hz 記錄氣壓計、環境光、機身溫度、磁力計至每趟 CSV，作為入水偵測與殼內氣壓行為的實驗資料 | 前三趟測試潛水可與潛水電腦剖面對照，回答「殼內氣壓是否只有一次階躍」 | P0 必要 |
