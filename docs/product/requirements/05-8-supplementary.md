# 5.8 補充功能

[← 需求文件索引](README.md)

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-91 | 預覽即所得：白平衡與色彩矩陣套在 Camera2 擷取請求上，預覽與成品同一管線，不在預覽上另加 GPU 濾鏡 | 預覽與成品 JPEG 的灰卡 RGB 差異 ≤ 5% | P0 必要 |
| FR-92 | 倒置介面：手機倒著拿時（鏡頭朝下，貼近底質拍微距）介面自動翻轉，快門區仍在拇指側 | 翻轉由重力感測觸發，可鎖定；照片方向標記正確 | P1 應有 |
| FR-93 | PRO 層：對焦峰值、斑馬紋、直方圖、三分線、中心點、安全區疊加，以及快門 / ISO / 白平衡色溫與色調 / 對焦距離手動；整組設定可存為自訂預設並出現在 FR-12 選擇器 | PRO 層預設隱藏，進入後控制元件仍守 FR-52 / FR-55 尺寸 | P1 應有 |
| FR-94 | 錄影 LOG 色彩描述檔與 LUT：錄影可選平坦色調曲線（Camera2 TONEMAP\_MODE\_CONTRAST\_CURVE），預覽套用選定的 .cube LUT；內建三段深度對應的 LUT，可匯入自訂 LUT | LUT 只影響預覽與後級，檔案保持 LOG | P1 應有 |
| FR-95 | 鏡頭鎖定：預設可指定固定實體鏡頭，禁止系統在變焦或近距時自動切換（裝濕鏡時必需，否則切到超廣角會拍到濕鏡邊框） | 以 Camera2 開啟單一實體鏡頭 ID 而非邏輯多鏡頭；實拍裝 0.6× 濕鏡無暗角 | P1 應有 |
| FR-96 | 手動輸入潛點座標與名稱，可從最近潛點清單選取 | 與 FR-42 同一欄位 | P2 可選 |
| FR-97 | 離線物種辨識：裝置上模型（印太區珊瑚礁魚類與無脊椎動物為主），回看時給學名、俗名與信心度，寫入 IPTC 關鍵字 | Top-3 準確率≥ 70%（以實拍照片集驗證）；不需網路 | P1 應有 |
| FR-98 | 離開 APP 的明確路徑：除 FR-51 長按解鎖外，鎖定畫面角落提供需連點兩次的「離開」鍵 | 兩種方式均不會因單次誤觸觸發 | P2 可選 |
