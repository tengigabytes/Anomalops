# 5.7 感測、對焦輔助與硬體擴充

[← 需求文件索引](README.md)

閃光燈與雷射對焦在殼內會被鏡頭罩反射，需以軟體關閉而非貼膠帶。閃光燈 Camera2 可完全控制；雷射測距模組沒有公開的 Camera2 控制鍵，只能靠對焦模式間接避免，需實測驗證。

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-81 | 潛水鎖定模式下閃光燈與手電筒硬性關閉：所有請求 FLASH\_MODE\_OFF，且不使用任何會觸發閃光燈的 AE 模式（ADR-0009）；介面不提供開啟選項 | 任何場景預設下閃光燈不觸發 | P0 必要 |
| FR-82 | 對焦以 PDAF 與手動對焦距離為主：微距與廣角預設使用 AF\_MODE\_OFF + LENS\_FOCUS\_DISTANCE 或 CONTINUOUS\_PICTURE，並實測雷射模組在各模式下是否發光（以另一支無 IR 濾鏡的相機觀察） | 找出不觸發雷射的 AF 模式組合並列為預設；若無法避免，在第 8 節記錄為限制 | P0 必要 |
| FR-83 | 入水 / 出水偵測：以氣壓計階躍（估 > 10 hPa / 2 s）搭配環境光度驟降判定，自動從陸上預設切到水下預設，並在照片中繼資料標記入水時間 | 先以 FR-45 實測確認階躍存在與幅度；偵測延遲 ≤ 5 s，可手動覆寫 | P1 應有 |
| FR-84 | 感測抽象層分兩個介面：即時的 DepthSource（手動深度、BLE 即時感測）與事後的 TelemetryImporter（潛水電腦 Log 對齊）；v1.0 只實作手動深度（ADR-0008） | 新增來源不修改拍攝管線程式 | P0 必要 |
| FR-85 | BLE 周邊協定預留：自訂 GATT 服務「Dive Sensor」，特徵值含深度（cm）、水溫（0.1°C）、方位（°）、快門（半按 / 全按 / 長按）、電量，1 Hz 通知 + 按鍵事件即時 | 協定文件完成；以模擬周邊通過整合測試 | P1 應有 |
| FR-86 | BLE 快門可取代觸控快門與預設切換（長按 = 下一個預設）；即時深度存在時自動切換白平衡深度段 | 按鍵到曝光 ≤ 200 ms | P2 可選 |

硬體模組本身（壓力感測器、BLE SoC、按鍵，安裝於殼外）屬於另一份硬體需求文件；它的關鍵限制是 2.4 GHz 在海水中的穿透深度只有公分級，模組天線必須緊貼殼壁、中間不能有水層（見第 8 節）。
