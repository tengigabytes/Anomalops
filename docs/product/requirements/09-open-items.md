# 9. 待決事項與後續版本規劃

[← 需求文件索引](README.md)

v1.0（MVP）的範圍、架構決策與驗收條件分別見 [mvp-scope.md](../mvp-scope.md)、[adr/](../../adr/README.md)、[mvp-acceptance.md](../mvp-acceptance.md)；長期里程碑見 [roadmap.md](../roadmap.md)。

以下事項需在進入設計階段前決定：

- [ ] 白平衡校正的基準：用商用灰卡，還是自製已知反射率的 PCB 白板？
- [ ] 深度分段邊界：淺 0–6 m / 中 6–15 m / 深 15 m+ 是否合理，還是依臺灣東北角與熱帶海域分兩組？
- [ ] 錄影是否需要 LOG 色彩描述檔？
- [x] APP 名稱與是否開源（tengigabytes 帳號下）。→ 2026-09-28 決定：開源，程式碼 GPL-3.0-or-later、文件 CC BY-SA 4.0；applicationId `io.github.tengigabytes.anomalops`，名稱沿用 Anomalops；Play 版以 Play Billing 提供樂捐。見[授權](../../release/licensing.md)與 [ADR-0010](../../adr/0010-flavors-and-donations.md)。
- [x] 預設檔式選 10-bit HEIC 還是 Ultra HDR JPEG？HEIC 較省空間，但分享相容性較差。→ 2026-09-28 決定：v1.0 用 JPEG\_R（不支援時 JPEG，FR-61a），10-bit HEIC（FR-61）延到 v1.1。
- [x] RAW 按需保留的觸發手勢：長按縮圖，還是快門區上方專用「保留 RAW」鍵？→ 2026-09-28 決定：長按縮圖（FR-62），泳池測試後若按不到再改。
- [ ] 雷射測距實測：需一支可看到 940 nm 的相機（舊網路攝影機或拆掉 IR 濾鏡的 Pi Camera）。
- [ ] BLE 感測模組是否由自己設計？若是，協定（FR-85）可在 v1 就定稿。
- [x] NFR-4「預設切換 ≤ 300 ms」是否也適用於需要換實體鏡頭的切換？→ 2026-09-28 G1 實測（[m1-instrumented.md](../../test/m1-instrumented.md)）：同一鏡頭的切換 143–215 ms；換鏡頭需重建工作階段，HAL 重建時間有波動，換鏡頭的 p95 為 374 ms。決定：拆成兩個門檻，同一實體鏡頭 p95 ≤ 300 ms，換實體鏡頭 p95 ≤ 450 ms（400 ms 時三次量測 394–410 ms，時過時不過）。暗處自動曝光把預覽降到 15 fps，延遲約加倍；試過把預覽固定在 30 fps，但照片會暗最多 1 EV 且偵測不到（ADR-0009 補註），因此不固定，NFR-4 只在 30 fps 的亮度下判定，暗處只記錄。

v0.1 審閱發現的文件內部不一致，每項決定後需回頭修正對應章節：

- [ ] 物種辨識的版本：FR-97 標為 P1（依版本表應在 v1.1），但版本表把「裝置上物種辨識」列在 v2.0。FR-97 降為 P2，或版本表移到 v1.1。
- [x] 潛水電腦對齊的版本：FR-44 標為 P0（v1.0），但版本表把「潛水電腦對齊 UI」列在 v1.1。需寫明 v1.0 是否只做對齊邏輯，以及「手動修正時鐘偏移」屬於哪一版。 → 2026-09-28 決定：FR-44 整項延到 v1.1，改為 P1。
- [ ] LOG 錄影：上方仍問是否需要，但 FR-94 已定為 P1 並有驗收標準。若決定不做，需同時刪除 FR-94。
- [x] 預設檔式：上方仍在 HEIC 與 Ultra HDR JPEG 間選擇，但 FR-61 已寫定 10-bit HEIC；5.1 節捷徑表稱 JPEG\_R 是「FR-61 的兩個實作選項之一」，FR-61 本文卻只有 HEIC；FR-91 驗收標準寫的是「成品 JPEG」。決定後統一三處。 → 已統一：新增 FR-61a，5.1 節捷徑表改指 FR-61a，FR-91 的「成品 JPEG」與 v1.0 一致。
- [x] RAW 保留手勢：上方仍在長按縮圖與專用鍵間選擇，但 FR-62 已寫定「長按預覽縮圖」。→ 已決定沿用 FR-62。
- [x] 快門與邊緣安全區：FR-52 要求快門佔「螢幕短邊整條區域」，FR-55 要求所有可點擊元件距四邊 ≥ 48 dp。需定義「整條」是否指內縮 48 dp 後的寬度。→ 2026-09-28 決定：安全區以 12 mm 為準（原文「約 48 dp」換算有誤，48 dp ≈ 7.6 mm，12 mm ≈ 76 dp），快門條寬度扣除兩側安全區。
- [ ] 連拍與 DNG：FR-68 規定連拍只存 HEIC、不存 DNG，FR-63 規定焦點堆疊自動保留 DNG，而焦點堆疊（FR-33）本身以連拍實作。需寫明焦點堆疊不適用 FR-68，或訂定優先順序。
