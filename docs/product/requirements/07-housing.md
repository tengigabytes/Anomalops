# 7. 防水殼與硬體配件整合需求

[← 需求文件索引](README.md)

v1 指定搭配 DiveVolk SeaTouch 4 系列（Max / Max Plus / Max Platinum，均 60 m 額定），APP 不需與防水殼通訊，但需針對它的物理特性設計。

| 防水殼特性 | 對 APP 的需求 |
| --- | --- |
| 甘油凝膠觸控膜，需裸指用力按壓 | 所有控制元件 ≥ 64 dp；只用點擊與長按；小於 44 dp 的元件不出現在潛水鎖定畫面 |
| 無實體快門，音量鍵依型號可能被遮 | 快門區域為螢幕短邊整條；音量鍵僅為備用 |
| 67 mm 螺紋可接廣角 / 微距濕鏡與色濾鏡 | 預設內可記錄「已裝鏡頭 / 濾鏡」，裝廣角濕鏡時不自動切到超廣角以免暗角 |
| 雙標準孔可裝托盤與潛水燈 | 潛水燈模式（FR-25）預設適用 D15VP II 這類 5000–6500 K 光源 |
| 無真空檢漏系統 | APP 不承擔檢漏；但潛水鎖定畫面永久顯示電量與機身溫度，溫度異常上升時警示 |
| 搭飛機時凝膠層可能產生氣泡 | 無 APP 需求，列入使用者教學 |

後續版本可考慮的硬體整合：藍牙潛水電腦即時深度（需在殼內，實際上只有線材穿殼可行）、外接閃燈以螢幕閃光觸發光纖。兩者都不在 v1。
