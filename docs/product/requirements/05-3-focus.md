# 5.3 對焦與微距

[← 需求文件索引](README.md)

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-31 | 微距預設自動選用有 AF 的超廣角（Pro）或主鏡頭裁切（非 Pro） | 對焦距離 ≤ 5 cm，輸出中心裁切不低於 12 MP | P0 必要 |
| FR-32 | 對焦鎖定與手動對焦滑桿（僅微距預設顯示） | 滑桿高度 ≥ 48 dp，長按預覽即鎖焦 | P1 應有 |
| FR-33 | 焦點堆疊（景深合成，廣角微距與長焦微距共用；對應 TG-7 Focus Stacking）：<br>1. 能力檢查：每顆鏡頭在執行時讀取 `LENS_INFO_FOCUS_DISTANCE_CALIBRATION`，依校準類型決定步進方式（ADR-0014）<br>2. 焦點包圍：連拍 5–8 張（可設定）不同對焦距離，步進依景深估算自動決定，總拍攝時間控制在數百毫秒內<br>3. 合成前先做縮放與位移對齊，處理焦點呼吸與平移<br>4. 合成演算法依 ADR-0015 選定<br>5. 保留每張 DNG（FR-63，不適用 FR-68）；合成失敗時輸出最清晰的單張<br>6. 在裝置上處理，不需網路（NFR-8） | 手持下合成成功率 ≥ 70%（G3、G4）；陸上腳架 6 張包圍總時間 ≤ 500 ms（提議，T9）；合成結果的清晰度不低於最清晰的單張，否則退回單張並保留全部 DNG；`UNCALIBRATED` 且沒有校正表的鏡頭不提供距離步進；待測項目見 [macro-stacking-test-plan.md](../../test/macro-stacking-test-plan.md) | P1 應有 |
| FR-34 | 顯微放大預覽 2× / 4×，以裁切方式實作 | 預覽延遲 < 100 ms | P2 可選 |
| FR-36 | 長焦微距：以 Camera2 從邏輯鏡頭指定望遠實體鏡頭（`setPhysicalCameraId`），`CONTROL_AF_MODE_OFF` 加 `LENS_FOCUS_DISTANCE` 手動對焦（FR-32 滑桿），繞過系統的鏡頭切換；畫面提示拍攝距離與構圖，提醒要拉開距離；可搭配 FR-33（ADR-0012、ADR-0013） | 望遠與最近對焦距離在執行時讀取，與能力表不一致時停用；陸上在 HAL 回報的最近對焦距離處拍解析度卡清晰（T1、T3）；距離提示顯示水中換算的大約距離（T8）；使用說明寫明代價：約 40 cm 的水層使懸浮物反光、對比下降，相同構圖下進光量比主鏡頭少約 3.3 級（皆為推算，T15、T16） | P1 應有（提議） |
| FR-37 | 構圖輔助：微距（FR-31、FR-36）時提示讓焦平面順著主體的長軸（例如從側面拍海蛞蝓），讓觸角和裸鰓落在接近同一個對焦平面；也提示殼與手電筒可能擋光的距離（T14）；不需額外運算 | 微距預設顯示提示，可關閉；不遮擋 FR-55 安全區內的按鍵 | P2 可選（提議） |
| FR-35 | AF 對比不足時自動退回該預設的固定對焦距離（LENS\_FOCUS\_DISTANCE），不往返拉風箱；不依賴雷射測距（裝殼後雷射測距無法使用） | 低對比場景拉風箱時間 < 0.5 s | P0 必要 |

**廣角微距**不另立編號：就是 FR-31 的微距預設加上 FR-33。v1.0 的鏡頭是超廣角 2× 裁切（mvp-scope 已凍結）；v1.1 起的預設鏡頭，依待測清單 T13 比較超廣角與主鏡頭後決定（ADR-0012）。距離太近時，殼或手電筒會在主體上投下陰影（第 8 節）。

2026-09-30：FR-33 擴充、FR-36 與 FR-37 新增（維護者同意撰寫者的盤點建議）。FR-36、FR-37 的優先度為提議。
