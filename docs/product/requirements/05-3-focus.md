# 5.3 對焦與微距

[← 需求文件索引](README.md)

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-31 | 微距預設自動選用有 AF 的超廣角（Pro）或主鏡頭裁切（非 Pro） | 對焦距離 ≤ 5 cm，輸出中心裁切不低於 12 MP | P0 必要 |
| FR-32 | 對焦鎖定與手動對焦滑桿（僅微距預設顯示） | 滑桿高度 ≥ 48 dp，長按預覽即鎖焦 | P1 應有 |
| FR-33 | 焦點堆疊：連拍 5–8 張不同對焦距離並合成（對應 TG-7 Focus Stacking） | 手持下合成成功率 ≥ 70% | P1 應有 |
| FR-34 | 顯微放大預覽 2× / 4×，以裁切方式實作 | 預覽延遲 < 100 ms | P2 可選 |
| FR-35 | AF 對比不足時自動退回該預設的固定對焦距離（LENS\_FOCUS\_DISTANCE），不往返拉風箱；不依賴雷射測距（裝殼後雷射測距無法使用） | 低對比場景拉風箱時間 < 0.5 s | P0 必要 |
