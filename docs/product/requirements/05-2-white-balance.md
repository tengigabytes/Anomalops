# 5.2 白平衡與色彩還原

[← 需求文件索引](README.md)

| ID | 需求 | 驗收標準 | 優先度 |
| --- | --- | --- | --- |
| FR-21 | 分深度白平衡預設：淺（0–6 m）、中（6–15 m）、深（15 m+），對應 TG-7 三段 | 每段對應一組預先校正的 RGB 增益與色彩矩陣，以實拍灰卡驗證 | P0 必要 |
| FR-22 | 一鍵自訂白平衡：對準灰卡或白色物點擊，儲存至 4 組記憶槽 | 不超過兩次點擊完成，記憶槽可命名並隨預設切換 | P1 應有 |
| FR-23 | 白平衡在 RAW 中以中繼資料保存，JPEG 則直接套用 | DNG 中 AsShotNeutral 與 JPEG 外觀一致 | P1 應有 |
| FR-24 | 已裝濾鏡設定（無 / 紅 / 洋紅），調整白平衡起點避免雙重校正 | 裝紅濾鏡時，淺水預設不再額外拿高紅色增益 | P0 必要 |
| FR-25 | 潛水燈模式：主體在燈光下時以燈色溫（5000–6500 K）為基準，避免背景水色被拉成紫紅 | 在 D15VP II 等常見潛水燈下實拍，背景水色保持藍綠 | P0 必要 |
| FR-26 | 出水後批次色彩還原：對整趟照片以裝置上模型重新估計水體色偏並補償 | 單張 50 MP 處理 < 2 s，可一鍵還原 | P1 應有 |
| FR-27 | 包圍白平衡：一次快門儲存三組不同色溫的 JPEG | 可在預設中開關 | P2 可選 |
