# 潛水鎖定平台行為測試（ADR-0006）：Pixel 10 Pro

2026-09-28 · 狀態：已完成（陸上、無防水殼）

| 項目 | 內容 |
| --- | --- |
| 裝置 | Pixel 10 Pro（`blazer`），Android 17，build `CP3A.260905.009` |
| 工具 | `:tools:probe` 的 `LockTestActivity`，從電腦用 adb 廣播指令驅動，每步截圖 |
| 起始條件 | 「應用程式固定」系統設定未開（`lock_to_app_enabled` 為 null）；APP 沒有「顯示在上層」與勿擾存取權 |
| 次數 | 每個情境 1–2 次。這是行為確認，不是統計量測 |

## 1. 結果

| # | 問題（ADR-0006「驗證」一節） | 結果 |
| --- | --- | --- |
| 1 | 非裝置擁有者呼叫 `startLockTask()` 會怎樣 | 跳出系統對話框「應用程式已固定」，說明「向上滑動並按住即可取消固定」。使用者按「知道了」之前，狀態維持 `NONE`；按下後變成 `PINNED`。**系統設定裡的「應用程式固定」不必事先打開** |
| 2 | 固定期間抬頭通知會不會出現 | **不會**。對照組：解除固定後，同一則通知 1.2 秒內就以抬頭通知出現。所以**不需要勿擾存取權** |
| 3 | 固定時按電源鍵關開螢幕 | 喚醒後直接回到我們的畫面，仍是 `PINNED`。當時手機被信任代理維持解鎖（`deviceLocked=0`），鎖定畫面被我們的畫面蓋住（`mKeyguardOccluded=true`） |
| 3b | 手機真正上鎖時，畫面能否蓋在鎖定畫面上（FR-56） | **能**。`deviceLocked=1` 時，重啟的畫面直接顯示在鎖定畫面之上 |
| 4 | 崩潰後能否在 3 秒內自動重啟 | 見第 2 節。可以：**449 ms**（固定中）、603 ms（未固定），要求是 ≤ 3,000 ms；固定狀態保得住，**不需要「顯示在上層」權限** |
| 5 | 手機上鎖時能否進入固定 | **不能**。畫面蓋在鎖定畫面上時呼叫 `startLockTask()`，沒有對話框，狀態維持 `NONE` |
| 6 | APP 內呼叫 `stopLockTask()` 解除 | 可以，解除後手機隨即上鎖（推測是系統「取消固定前要求 PIN」的預設行為） |
| — | 最高亮度、隱藏系統列 | 系統紀錄顯示亮度被覆寫為 100%（約 1450 nits）；狀態列與導覽列都隱藏 |
| — | 解除固定的手勢（上滑並按住）在殼內會不會被誤觸 | **未測**，要到泳池（G3） |

## 2. 崩潰重啟：三種情況

| 做法 | 結果 |
| --- | --- |
| 在崩潰中的程序裡重新啟動同一個 `singleTask` Activity | **重啟失敗**：請求跟著程序一起消失。task 變空後，**固定也跟著解除**（`NONE`） |
| 同上，但 task 裡還有其他 Activity | 固定保住了，但回到前景的是 task 裡的其他畫面，不是我們要的畫面 |
| **跳板**：崩潰處理器先在同一個 task 啟動一個透明 Activity，它跑在另一個程序（`:restarter`）；0.3 秒後由它重新開啟主畫面，再關掉自己 | **成功**：task 一直沒變空，固定保住，449 ms 後主畫面回來 |

實作在 `tools/probe/.../CrashRestarter.kt` 與 `RestartTrampolineActivity.kt`。

## 3. 對設計的影響

1. **進入潛水鎖定必須在手機解鎖時做**（第 5 項）。下水前本來就是解鎖狀態，但 FR-58 下水前檢查清單（P1）應包含「按下固定確認」。在 v1.0 沒有 FR-58 的情況下，由進入鎖定的流程引導使用者完成。
2. **水下無法重新固定**：水下藍牙信任裝置斷線，手機一定是上鎖的。所以崩潰處理**必須讓 task 保持不空**，跳板方案是必要的，不是選配。
3. **權限比 ADR-0006 預期的少**：不需要勿擾存取權（固定本身就擋掉抬頭通知），也不需要「顯示在上層」權限（跳板在前景視窗還在時就啟動）。
4. **確認對話框的按鈕位置**：「知道了」在螢幕右下角，在殼內要能按到。這一點要在泳池測試時一併確認（FR-55 安全區）。

## 4. 還沒驗證的

| 項目 | 何時 |
| --- | --- |
| 固定中、手機**真正上鎖**時按電源鍵關開 | G2（殼內水浴，藍牙信任裝置不在時） |
| 在殼內、水壓下，解除固定手勢會不會被誤觸 | G3 泳池 |
| 崩潰重啟的重複性（多次、連續崩潰） | M3 實作潛水鎖定時寫成自動化測試 |
| 其他手機型號、其他 Android 版本 | M11 |
