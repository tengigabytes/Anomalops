# M9 前置：GPU 合成的記憶體（T11，ADR-0017 第 6 步）

2026-10-02 · 狀態：陸上量測完成；開著預覽、RAW 緩衝滿載時，最高是 FR-33 候選 B 八張：PSS 485.6 MB（其中 GPU 375.6 MB）加相機 dma-buf 189.5 MB，沒有崩潰也沒有被系統終止

手機 blazer（Pixel 10 Pro），debug 版（記憶體不受 debug 影響；時間不計）。`:app` 的 `experiment/GpuMemoryExperiment`。

## 1. 量法

- 用驗收測試的 `AppRig` 開相機：預覽串流持續，FR-62 的 RAW 緩衝（5 張、10 秒）以拍 5 張靜態照填滿。
- 依序做 FR-17（5 張）、FR-33 候選 A 與 B（各 8 張，含 `GpuStackGuard`），每張 RAW 在 GPU 上解碼後加入。GPU 持有最多的時候是最後一張加入之後、`finish` 之前：這時拍 5 張填滿 RAW 緩衝，再讀記憶體；接著 `finish`、全部釋放，再讀一次。
- 每張合成用的 RAW 在 CPU 上當場產生（Java heap 裡只有一張），而且已經對齊，所以不含對齊用的金字塔。
- 讀數：先做一次記憶體回收，`dumpsys meminfo` 的 TOTAL PSS、Graphics、GL mtrack、Java heap、Native heap，以及 `/proc/self/fdinfo` 的 dma-buf（RAW 緩衝在這裡，PSS 看不到，見 [m2-instrumented.md](m2-instrumented.md)）。

## 2. 結果（MB）

| 時間點 | PSS | 其中 Graphics（= GL mtrack） | Java heap | Native heap | dma-buf |
| --- | --- | --- | --- | --- | --- |
| 預覽中 | 61.9 | 0.0 | 8.5 | 7.6 | 4.8 |
| 預覽中、RAW 緩衝滿 | 66.1 | 0.0 | 9.3 | 8.7 | 187.2 |
| GL 環境、解碼器、4 個平面（緩衝已清） | 134.5 | 49.8 | 9.4 | 13.8 | 187.2 |
| FR-17 5 張加入後、RAW 緩衝滿 | 326.6 | 199.2 | 34.4 | 30.8 | 187.2 |
| FR-17 釋放後 | 201.8 | 77.3 | 34.3 | 28.0 | 187.2 |
| FR-33 A 8 張兩輪後、RAW 緩衝滿 | 444.7 | 334.9 | 34.3 | 13.3 | 189.5 |
| FR-33 A 釋放後 | 189.2 | 80.1 | 34.3 | 12.6 | 189.5 |
| FR-33 B 8 張加入後、RAW 緩衝滿 | 485.6 | 375.6 | 34.3 | 13.5 | 189.5 |
| FR-33 B 釋放後 | 190.3 | 80.9 | 34.3 | 12.9 | 189.5 |
| GL 環境關閉後 | 108.5 | 0.5 | 34.3 | 11.5 | 189.5 |

- **最高**：FR-33 B，PSS 485.6 MB 加 dma-buf 189.5 MB，合計約 675 MB；GPU 的部分（Graphics）375.6 MB。FR-33 A 合計約 634 MB，FR-17 約 514 MB。過程中沒有崩潰、沒有被系統終止（T11 的通過標準）。
- **GPU 記憶體與張數無關**：合成只持有累加的平面（ADR-0017 第 2 節），張數不會讓它變大。扣掉釋放後仍在的約 80 MB（實驗自己的 4 個平面 50 MB、RAW 紋理約 25 MB 與查表），合成本身約 FR-17 120 MB、FR-33 A 255 MB、B 295 MB（推測：以相減估計）。
- **dma-buf 清掉緩衝後沒有降回來**：從填滿之後一直是 187–190 MB。這是相機 RAW 讀取器的緩衝池（ADR-0005，最多 7 個），不是 GPU；與 FR-62 記憶體測試看到的一致（[m2-instrumented.md](m2-instrumented.md)）。
- Java heap 從 9 MB 升到 34 MB 是產生測試 RAW 的程式（每張 25 MB 的陣列），不是合成。

## 3. 還沒做的

- 實際流程的 RAW 會直接來自緩衝（相機的 `Image`），不必複製到 Java heap；要接上 `:app` 時再量一次。
- 對齊用的金字塔（約 1.33 個平面）沒有算進來。
- 若之後要降 GPU 記憶體：B 的各色版金字塔、半精度（ADR-0017 第 3 節，第 4 步做顏色時重新評估）。
