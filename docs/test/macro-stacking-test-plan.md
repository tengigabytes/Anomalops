## 3. 順序

T1、T2 排在最前面：長焦微距與包圍步進都依賴實體鏡頭存取與校準類型（roadmap M9 前置工作）。接著 T3–T5（校準），再做 T9–T12（包圍與合成），最後是需要裝殼或下水的 T8、T13–T15、T17。

## 3.1 測試靶（2026-10-01）

`python scripts/make_charts.py` 產生四張 A4 測試靶（PDF，預設在 `build/charts/`），以 100%（實際大小）列印，先用尺量每張下方的 100 mm 比例尺：

| 靶 | 用途 |
| --- | --- |
| A 平行對焦靶 | 正對鏡頭：T3、T4 細掃（中央星形與枯葉紋理在任何距離都有細節）、T6 畫面寬（四邊 mm 刻度）、T12 實拍 |
| B 斜放景深尺 | 斜放：T7、T10、T9 重驗（`SlantedRulerExperiment`）；量距離到中央「0」線 |
| C 距離尺 | 剪三條接成 0–72 cm，「0」端貼齊鏡頭玻璃，量 T3、T4 的距離 |
| D 灰階與解析度 | T16 以均勻色塊比較雜訊；線對 0.5–4 lp/mm 給 ADR-0011 各倍率的清晰度 |

印表機的灰不是標準灰卡，D 只作相對比較；校正白平衡仍要用灰卡（需求第 9 節待決）。

## 4. 下次要做（2026-10-01 維護者排定）

**斜放直尺：T7、T10，並重驗 T9**。目的：看出焦點包圍時每一張實際對在哪裡（T9 發現拍攝時鏡頭還在移動），以及清晰範圍有多深，決定包圍要「一張換一個距離」還是「每個距離停 2–3 幀」。

擺法：
1. 桌上放測試靶 B（斜放景深尺），或一把刻度清楚的直尺（30 cm 最好）。
2. 手機固定，從斜上方約 45 度往下看著尺，鏡頭對準尺的中間，距離約 35–40 cm（望遠可對焦的範圍）。
3. 燈打亮；Google 相機開著也可以，開跑前會先關掉。
4. 告訴 Claude 尺的中間離鏡頭大約幾公分。

測試程式還沒寫：`MacroFocusExperiment` 要新增一項，對同一張直尺拍焦點包圍（一張換一個距離、每個距離停 2–3 幀兩種），逐張算清晰帶落在尺上哪一段。之後是 T6、T16（T5 已於 2026-10-01 完成）。
