# M1 成品寫入 MediaStore 實機測試（Pixel 10 Pro）

2026-09-28 · 狀態：已完成（手動測試；NFR-7 的 300 張與 FR-61a 的 `hasGainmap()` 儀器測試另做）

分支 `m1/mediastore`，`fossDebug` 版。以 adb 點擊 M1 測試畫面，五種預設各拍一張，共兩輪 9 張（第一輪因測試腳本點錯位置少一張，見第 3 節）。照片留在手機上，只用 `content query` 讀 MediaStore 欄位，並把檔案位元組串流進記憶體檢查結構，照片不落地到電腦。

## 1. MediaStore 紀錄

| 項目 | 結果 |
| --- | --- |
| 位置 | 9 / 9 在 `Pictures/Anomalops/`（ADR-0004） |
| 狀態 | 9 / 9 `is_pending = 0`，`mime_type = image/jpeg`，擁有者為本 APP |
| 尺寸 | 鏡頭 2：4080 × 3072；鏡頭 3、9：4032 × 3024 |
| 檔案大小 | 1.64–3.73 MB，都在 FR-61a 的 6 MB 以內 |
| 寫入耗時（呼叫到 `IS_PENDING = 0`） | 60–111 ms；APP 啟動後第一張 208 ms（推測為冷啟動） |
| 權限 | 不需儲存權限，manifest 未變 |

## 2. 檔案內容（第二輪 5 張）

| 檢查 | 結果 |
| --- | --- |
| JPEG 起始標記數 | 5 / 5 為 2 個（主影像 + 增益圖） |
| MPF 索引 | 5 / 5 有 |
| Ultra HDR XMP（`hdrgm`） | 5 / 5 有 |
| EXIF orientation | 5 / 5 為 6（順時針轉 90°），對應感測器方向 90° |

增益圖以檔案結構判斷存在；驗收要求的 `Bitmap.hasGainmap()` 留給儀器測試。維護者在相簿檢視，直拿手機拍的照片方向正確（2026-09-28）。

## 3. 發現並修正

存檔後狀態列加上檔名，文字換成兩行，把預設列與快門鍵往下推 72 px，固定座標的點擊落空而少拍一張。這在實際使用時同樣會讓按鍵在手指下移動，因此把狀態列固定為兩行高（超出以省略號截斷）；修正後拍攝前後按鍵座標不變。
