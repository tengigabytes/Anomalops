# docs/ 編輯規則

- 用臺灣正體中文寫；程式識別字與 API 名稱保留原文，用程式碼格式。
- 第三行是狀態列：`日期 · 狀態：…`。
- 單檔 ≤ 300 行或 20 KB，超過就拆成目錄並加索引。
- 新增、刪除、改名檔案時，同一次修改就更新該目錄的 `README.md` 索引。
- 需求以編號引用（FR-62、NFR-4、ADR-0005），用 grep 找，不要整批讀取 `product/requirements/`。
- 已採納的 ADR 不改寫，只能補充註記，或另寫新 ADR 取代。
- `product/mvp-scope.md` 已凍結，修改要照它第 5 節的變更規則。
- 推測的內容標示「推測」，並寫明要在哪個關卡驗證。
- 改完執行 `python scripts/check_limits.py`。
